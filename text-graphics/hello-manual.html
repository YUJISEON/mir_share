글자 그래픽 스크립트 사용 매뉴얼

글자를 붓으로 그리듯 보여주는 캔버스 스크립트(hello-demo.html)를 다른 단어 · 색 · 문구로 바꿔 쓰는 방법을 정리했습니다.

새 단어로 바꾸는 순서

  1. 글자 좌표 적기 — 520×520 모눈에서 글자마다 획 경로를 정해 SEG 에 적습니다. 1장
  2. 외곽 범위 적기 — 글자별 바깥 경계를 BOX 에 적습니다 (좌표의 최소 · 최대값에서 획 두께 절반만큼 넓힘). 4장
  3. 장면 추가 — SL 에 글자마다 한 줄씩, 색 · 문구 · 질감을 적습니다. 4장
  4. 단어 표시 바꾸기 — WORD 와 합체 장면 문구를 바꿉니다. 4장
  5. 확인 — 브라우저에서 열어 보고, 윤곽선 · 빗금의 어긋남이나 속도를 조정합니다. 2장 · 3장

버튼 개수와 장면 번호는 SL 의 줄 수에 맞춰 자동으로 만들어지므로 HTML 은 고칠 필요가 없습니다.

1. 글자 좌표 보기

520×520 모눈 위에 각 글자의 좌표가 어디에 찍히는지 보여줍니다. 글자를 고르고, 오른쪽 코드 줄을 누르면 해당 선이 강조됩니다.

모눈 위에 마우스를 올리면 그 위치의 좌표가 표시됩니다.
실제로 칠해지는 굵은 획 (두께 72)
좌표로 적는 중심선 (화살표 = 붓이 가는 방향)
코드에 적힌 좌표점
① ② ③ = 획 순서 (붓을 떼고 새로 시작하는 단위)

2. 글자 뒤에 겹쳐진 요소

하얀 윤곽선과 빗금 그림자는 따로 만든 도형이 아니라, 위와 같은 글자 좌표를 위치만 살짝 옮겨 다시 그린 것입니다. 위에서 고른 글자 기준으로 보여줍니다.

③ 글자 본체 — 맨 위
좌표 그대로, 두께 W(72), 그라디언트 색.
② 빗금 그림자 — 중간
같은 글자를 두께 W(72) 그대로, 옮겨서 그림. 색 대신 대각선 무늬(hatch)로 칠함. 글자와 같은 속도로 그려짐.
① 하얀 윤곽선 — 맨 아래
같은 글자를 옮겨서 그림. 본체보다 사방 25 만큼 큰 테두리. 색은 ring, 옮기는 양은 ro. 글자가 60% 쯤 그려지면 서서히 나타남.
옮기는 방향: x 는 +면 오른쪽, −면 왼쪽 / y 는 +면 아래, −면 위.
빗금의 (−30, +18) 은 모든 글자 공통으로 코드에 고정돼 있고, 윤곽선의 ro 는 글자마다 SL 에서 따로 정합니다.

3. 하얀 윤곽선이 만들어지는 과정

가는 선을 직접 그리는 게 아니라, 굵은 선을 그린 뒤 조금 덜 굵은 선으로 속을 파내서 테두리만 남깁니다.

1. 두께 W + 50 = 122 로 글자를 그림
2. 두께 W + 47 = 119 로 같은 자리를 지움 (어두운 부분이 지워질 영역)
3. 차이 3 의 절반인 1.5 두께 테두리만 남음

4. 커스텀 가능한 부분

hello-demo.html 기준입니다. 대부분 SL 배열의 글자별 한 줄에서 값만 바꾸면 됩니다.

항목바뀌는 부분예시 값

질감 안쪽 색(네트워크의 점과 선, 빛 번짐, 얼룩)은 SL 이 아니라 texture() 함수 안의 rgba(...) 값을 직접 고쳐야 합니다. 버튼과 문구의 색은 CSS 에서 바꿉니다.

글자 모양과 두께

항목바뀌는 부분주의
SEG글자의 획 경로 (선 · 호 좌표)새 글자는 좌표를 직접 적어야 함
shape장면에서 쓸 글자 모양 (SEG 의 키)같은 모양을 여러 장면에서 재사용 가능
W획 두께. 본체 · 빗금 · 윤곽선이 함께 바뀜바꾸면 BOX 도 같이 조정
BOX합체 장면에서 글자의 폭과 중심 계산획 두께 절반을 포함한 바깥 경계
ro윤곽선을 글자에서 어긋나게 두는 양 [x, y]글자마다 따로 지정
-30, 18빗금 그림자를 어긋나게 두는 양draw() 안, 모든 글자 공통
W + 50, W + 47윤곽선과 글자 사이 거리, 윤곽선 굵기drawStatic() 안
빗금 간격 8빗금 줄 사이 간격 (px)hatchPattern() 의 기본값

곡선은 원호만 지원합니다. 획이 굵어서 한글이나 획이 많은 글자는 W 를 크게 줄여야 뭉개지지 않습니다.

질감 — SL 의 tex

값모습세부 조절 (texture() 안)
'network'떠다니는 점과, 가까운 점끼리 잇는 선점 개수 60, 연결 거리 88, 속도 .35
'photo'천천히 흔들리는 어둡고 밝은 얼룩얼룩의 위치 · 크기 · 색, 속도 2200
'glow'글자 둘레를 도는 빛 2개빛의 크기 · 색, 회전 속도 1800

질감 종류를 새로 만들려면 texture() 에 else if (sl.tex === '이름') 분기를 추가하면 됩니다. 속도 숫자는 클수록 느립니다.
